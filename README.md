## 🏗️ System Architecture

The internship project followed a three-tier architecture consisting of the presentation layer, application layer, and data layer.

```text
             USER / CLIENT
                   |
                   v
       +-----------------------+
       |   PRESENTATION LAYER  |
       |   HTML, CSS, JS       |
       +-----------------------+
                   |
              HTTP Requests
                   |
                   v
       +-----------------------+
       |   APPLICATION LAYER   |
       |   Java + Spring Boot  |
       |   REST APIs           |
       |   Business Logic      |
       +-----------------------+
                   |
              SQL Queries
                   |
                   v
       +-----------------------+
       |       DATA LAYER      |
       |   Relational Database |
       |   Data Storage        |
       +-----------------------+
```

### Architecture Explanation

**1. Presentation Layer**

Responsible for displaying the user interface and handling user interactions using HTML, CSS, and JavaScript.

**2. Application Layer**

Responsible for processing client requests, implementing business logic, and exposing REST APIs using Java and Spring Boot.

**3. Data Layer**

Responsible for storing, retrieving, and managing application data using a relational database.
