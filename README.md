# Deloitte Data Analytics Job Simulation

## 📌 About the Internship

This repository contains my work and learning outcomes from the **Deloitte Data Analytics Job Simulation**, a virtual internship program hosted on the **Forage platform**.

The simulation provided practical exposure to the responsibilities of a **Data Analyst within Deloitte's Forensic Technology practice**, including data cleaning, data analysis, anomaly detection, data visualization, and communicating data-driven insights to non-technical stakeholders.

## 🎯 Objectives

- Understand the application of Data Analytics in Forensic Technology
- Perform data cleaning and preprocessing
- Analyse structured datasets to identify patterns, trends, and anomalies
- Create meaningful data visualizations
- Convert analytical results into clear, business-oriented insights
- Understand a professional data analytics workflow
